# Canonical skill taxonomy

`skills_taxonomy.json` is a curated STARTER taxonomy (~110 entries),
generated by `scripts/build_skill_taxonomy.py` -- edit that script and
rerun it to add/change entries rather than hand-editing the JSON.

It is not an exhaustive industry-standard taxonomy (e.g. ESCO or O*NET
have thousands of entries and require data sources outside this
environment's reachable network); it's a reasonable curated set for an
project's starter taxonomy, covering common languages, frameworks,
databases, cloud/DevOps tools, data/ML terms, and practices -- each with
genuinely-equivalent alias phrasings (not merely related concepts).

See `normalization/normalizer.py` for how it's matched against (exact/
alias lookup, then fuzzy matching via rapidfuzz above a fixed threshold).
